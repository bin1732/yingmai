## 简介

盈脉是一款面向国内与跨境电商从业者的本地桌面软件，覆盖选品、竞品、商品、库存、采购、订单、发货、售后、客户、定价、广告、费用、利润、合规与文案等日常经营场景。

软件**内置可离线使用的 AI 模型，安装后双击即可使用**，无需安装其他工具，也不依赖联网；推理在本机完成，业务数据保存在本机。如有需要，也可以在设置中接入您自己的云端 API 或本地大模型获得更强能力。

## 产品特点

- **开箱即用**：双击安装，无需 Ollama、LM Studio 或 Python。
- **离线 AI 助手与离线语音识别**随软件提供。
- **店铺连接器**：用您自己的凭证在本机直连平台，凭证经加密后仅保存在本机。
- **真实记账**：逐单核算损益、费用台账与平台对账。
- **中英双语界面**、浅色/深色主题与现代毛玻璃外观。

## 安装与使用（Windows）

1. 双击 `盈脉 Setup 4.6.0.exe`；
2. 按提示完成安装（可自行选择安装目录），安装程序会创建桌面与开始菜单快捷方式；
3. 双击桌面的「盈脉」图标即可开始使用。

> 不想安装？也可以直接双击 `盈脉-便携版.exe`，首次运行会自动准备文件（首次约需几十秒），之后再次打开只需一两秒。
> 内置模型已随软件提供，无需安装 Ollama、LM Studio 或 Python。

首次打开会出现「用户引导」，带您快速了解核心功能；可随时跳过，也可以在「设置」中重新打开。

## 随包模型

软件包含两个本地模型文件，用于离线对话与语音输入：

| 模型 | 作用 | 大小 |
|------|------|------|
| Qwen2.5-1.5B-Instruct（q4_k_m，GGUF） | 离线 AI 助手 | 约 1.04 GB |
| SenseVoice（int8，ONNX） | 离线语音识别（普通话、粤语、英语、日语、韩语） | 约 0.23 GB |

**大多数用户无需任何额外操作**：Releases 中的安装包与便携包已内置上述文件，下载后即可使用。

模型二进制文件**不通过本 Git 仓库提交**，这与 llama.cpp、whisper.cpp 等项目不把模型放入 Git 的做法一致：文件较大、保持源码轻量，并可从各地均可稳定访问的镜像获取。从源码运行或打包时，执行 `npm run setup` 即可从可访问的镜像下载，并校验文件大小与 SHA-256。项目不依赖 Git LFS，贡献者无需安装额外工具。

**按需选择更强的本地模型**：在「设置 → 本地模型（可选）」中，软件会检测本机的显卡与内存并标注推荐档位，可在轻量、均衡、增强三档中选择模型下载；下载后在本机直接运行，不依赖 Ollama、LM Studio 等其他软件。默认内置模型保持不变，不下载也能完整使用。

## 功能模块

| 模块 | 说明 |
|------|------|
| 仪表盘 | 经营概览、趋势、平台分布、快捷入口、AI 引擎状态、销售热力图 |
| 电商助手 | 全局悬浮，可语音或文字解答规则、费用、操作与数据问题 |
| 店铺连接 | 用您自己的店铺凭证在本机直连平台，自动同步订单、商品与库存；凭证仅保存在本机 |
| 商品库 / 店铺商品 | 内部商品主数据（SKU、成本、安全库存）与各平台店铺商品映射 |
| 库存管理 / 仓库管理 | 多仓库、库存结存、不可改动的库存流水台账、仓库间调拨 |
| 采购管理 | 采购下单、收货入库、在途与收货进度 |
| 订单与发货 | 订单状态流转、发货处理、物流信息、待发货提醒 |
| 售后管理 | 仅退款、退货退款、补发、换货处理，并自动联动库存 |
| 客户管理 | 客户分层（RFM）、复购、客单价、客户价值与同期复购分析 |
| 经营损益 | 按订单逐笔核算收入、成本、平台费用、广告与净利润，支持结算对账 |
| 预警中心 | 缺货、发货超时、退款偏高、滞销等主动提醒 |
| 选品 / 竞品分析 | 需求、竞争、利润空间评估，Listing 与卖点对比 |
| 卖前体检 | 上架前按主体资质、类目、品牌、认证、标签与物流逐项核对，给出材料清单与需要核实的门槛 |
| 定价建议 | 结合成本、平台费率、目标利润率与竞品价格带给出建议售价，并展示价格—利润曲线 |
| 评论分析 | 评价洞察、差评归因，并可把问题加入改进清单跟踪 |
| Listing / 客服话术 | 标题、五点、描述与常见客服回复生成 |
| 关键词 / 广告 | 关键词覆盖与违禁词检查，ACOS、TACoS、竞价与盈亏测算 |
| 物流方案 | 国内外主流物流渠道时效与费用参考 |
| 平台规范中心 | 各平台入驻条件、费率与规则参考 |
| 合规检查 | 上架前合规自查 |
| 提示词库 / 文案优化 | 电商场景提示词模板，让商品文案更自然、更可信 |
| 入行指引 | 从身份准备到出单经营的分步指引 |
| 设置 | 深浅色主题、中英双语、用户引导、AI 引擎配置、数据导入导出 |

## 支持平台

**国内**：淘宝、天猫、京东、拼多多、抖音电商、快手电商、小红书电商

**跨境**：Amazon、Shopee、TikTok Shop、Shopify、eBay、AliExpress、Lazada 等

> 各平台连接器的接入条件不同，以应用内「店铺连接」页面标注与官方链接为准：**Shopify 可直接连接**；**Amazon、eBay** 可凭自有开发者凭证按教程自助授权连接；**Shopee、AliExpress、TikTok Shop、Lazada、1688 货源**需先在对应开放平台注册开发者并通过平台审核；淘宝/天猫、京东、拼多多、抖音电商、快手电商、小红书的订单类接口主要面向企业及认证服务商，个人卖家通常无法自助直连，仍可继续使用手工录入与文件导入。

## AI 引擎

- **内置模型**：本地推理引擎直接加载，开箱即用、无需联网；启动时自动预热，打开即可快速响应。
- **云端增强（可选）**：支持接入 DeepSeek、通义千问、智谱 GLM、月之暗面、硅基流动、OpenAI 等 OpenAI 兼容服务。选择服务商、填入对应 API Key 后点击「检测可用模型」，会列出该 Key 下真实可用的模型供选择；并提供各服务商官方申请入口。
- **本地模型（可选）**：可自动检测并调用本机 Ollama、LM Studio 等 OpenAI 兼容方式部署的模型。
- 对话界面会显示当前实际使用的模型与用量情况，接入、切换与切回均真实生效。

## 语音输入

电商助手支持语音说话转文字，方便不熟悉打字的用户。语音识别模型与运行库均已随软件内置，**无需联网、也无需另外下载**，开箱即可离线使用，支持普通话、粤语、英语、日语、韩语。

## 硬件适配

软件会自动检测设备的显存与硬件，匹配上下文长度与推理方式，兼顾不同配置的电脑。

| 配置 | 体验 |
|------|------|
| 8GB 显存及以上 | 流畅，支持更长上下文 |
| 4GB 显存 | 可正常使用，GPU 与 CPU 协同 |
| 仅 CPU / 核显 | 可用，速度相对较慢 |

## 数据安全与合规

- 内置模型推理在本地完成，默认不上传业务数据；您的 API Key 仅保存在本机，不会随软件分发。
- 支持单类数据与整包数据的导出、导入和备份，便于迁移与留档。
- 平台规则、费率与物流信息为参考值，请以各平台官方最新公告为准。
- 软件不提供刷单、虚假宣传、侵权、避税等任何违规操作指导。

软件采用 Electron 原生桌面架构，分为表现层、接口与应用服务层、AI 引擎与领域核心、平台连接器、数据与模型层。详见 [架构总览](docs/architecture.html)。

## 从源码运行与构建

> 面向开发者；普通用户直接使用安装包或便携版即可，无需本节操作。

```bash
# 1. 安装依赖
npm install

# 2.（可选）下载随包模型；仅运行测试或查看界面无需此步
npm run setup

# 3. 本地运行
npm run app

# 4. 运行测试（仅依赖 Node 内置模块，无需联网或模型）
npm test

# 5. 构建安装包与便携版
npm run dist
```

支持的 Node.js 版本为 18 及以上。模型二进制文件不通过 Git 提交（见[随包模型](#随包模型)）；执行 `npm run setup` 可下载并校验，或直接使用 [Releases](https://github.com/bin1732/yingmai/releases) 中已内置模型的安装包。
